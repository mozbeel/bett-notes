### propositional logic

- can something be allocated (answered with true or false)

- is one part of binary logic (p, q)

e.g. How are you? -> non-allocatable
     Vienna is the capital of Austria -> allocatable

### binary logic

- sentence is true or false

- is all parts of propositional logic (p && q)

e.g. How are you? -> cannot be answered (non-allocatable)
     Vienna is the capital of Austria -> true

### notation

**propositional logic** -> p, q, r, s

**boolean terms** -> a, b, c, d

**logical values** -> positive/true (t, +, 1, ...) negative/false (f, -, 0, ...)
