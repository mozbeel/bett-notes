#CABS 
Betriebssystem ist eine Stueck Software zwischen der Hardware und den User (Powerpoint, Word, Excel, Browser, ...).

Kernel: Core of the operating system
Userspace: Anwendungen
Driver: Bestimmte Hardware ansprechen koennen
Shell: Moeglichkeit mit dem Betriebssystem kommunizieren zu koennen

Beispiel.:. 
Visual Studio bestimmt nicht das File System, kommuniziert nur mit dem Betriebssytem, was mit der File System managed.
