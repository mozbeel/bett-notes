#BWM #Accounting #P22
What do we need to assess:
- balance sheet
- P&L

Which assets:
- fixed assets
- Umlaufvermögen (current assets):
	- how many on stock
	- assess the value
	- -> make a booking line correcting the loss
	- assess the receivables:
		- if not paid yet, maybe not paying?
- equity:
	- was there any private withdrawl?
	- was there money put in?
- borrowed capital:
	- debt assessement


Principles:
- Niederstwertprinzip (principle of lowest value): assets
	- never allowed to assess the value higher than the buying price
		- if you buy a asset for 10€ -> initially at 10€
		- and it loses to 8€ -> goes to 8€
		- then 9€ -> can go up to 9€
		- then 11 -> still 10€
	- 31st dec: not the same as the buying price, put the lower price in the balance sheet
- Hoechstwertprinzip (principle of highest value): borrowed capital:
	- highest possible price
	- minimum: historical pay-back value
		- borrowed 100,000 in USD -> 100,000 EUR
		- exchange rate changed -> 92,000 EUR
		- still have to pay back 100,000 EUR
	- 31st dec: pay-back value != actual value, decide the higher pay-back value
